The most boring object is the paperclip: it does exactly one unglamorous job, and even that only briefly, before spending the rest of its life bent out of shape in a drawer holding nothing at all. The review treats that quiet failure as its whole personality — a tiny metal shrug.

## Run

```sh
node main.ts
```

This writes the one-line review (150 characters) to `/output/entry.txt` with no trailing newline. Set `MAKEFUN_OUTPUT_DIR` to write elsewhere for local testing.
